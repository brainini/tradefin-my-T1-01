## 3. 교차 점검 — 문제없음으로 확인된 것

| 점검 | 결과 |

| 7 | industry 빈칸 5건 | 업종 |
| 8 | 결제조건 `10% T/T advance + 90% O/A 90 days`, `tt`/`TT` | 표준 코드 판정 (사전은 `TT`→TT_ADV로 두지만 원천에 기간 정보 없음) |
| 9 | B087 센트 단위 금액 | 다른 행과 입력 기준이 다른가 |

## 재현 방법

```
uv run python scripts/d1_quality_diagnose.py
```

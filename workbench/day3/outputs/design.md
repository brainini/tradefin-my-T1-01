## 1. 레퍼런스에서 가져올 것 · 가져오지 않을 것

**가져올 것 (3줄)**

| # | 무엇 | 어디서 | 우리 보드에서 |
|---|---|---|---|
| 1 | 작은 회색 머리말 → 크고 굵은 제목 → 작은 회색 설명 한 줄의 3단 글자 위계 | ref2 왼쪽('성과' → 큰 제목 → 설명), ref1 머리 | 머리(제목 · 기준일)와 구역 제목마다 같은 3단 |
| 2 | '큰 굵은 숫자 + 그 아래 작은 회색 근거 한 줄'을 가는 가로줄로 나눠 쌓는 목록 | ref2 오른쪽(+23% · 1.7배 · 3억 + 출처 한 줄) | KPI 4개 — 숫자 아래에 계산 근거 한 줄(예: '150곳 중 · `open_ar_usd` 합') |
| 3 | 1px 테두리 카드를 격자로 놓고 중요한 카드 하나를 2칸 폭으로 넓히는 배치 · 카드 안 넉넉한 안쪽 여백 · 글은 왼쪽 정렬 | ref1 카드 격자(둘째 카드가 넓음) | 등급 분포 + 슬라이더 카드를 넓게, 지역별 채권 · 상위 10을 같은 격자에 |

**가져오지 않을 것 (3줄)**

| # | 무엇 | 이유 |
|---|---|---|
| 1 | 그림 · 로고 — 사람 사진(아바타), 회사 이름 · 로고, 반짝이 아이콘 | 남의 자산이고 우리 화면에 뜻이 없다 |
| 2 | 글 — 영어 후기 인용문, '20K+ DEVELOPERS' 같은 홍보 문구, 레퍼런스의 성과 숫자 | 내용은 우리 바이어 데이터로만 채운다 |
| 3 | 색 — 파란 강조색, 바탕의 파랑 기운 원형 그라데이션, 알약 모양(완전히 둥근) 단추, 양옆 점선 장식 | 색은 우리 토큰으로, 그라데이션 · 큰 둥근 모서리 · 장식은 'AI 티' 금지 목록에 걸린다 |

## 4. 'AI 티' 금지 목록

| 금지 | 대신 |
|---|---|
| 보라 · 파랑 그라데이션 | 레퍼런스 이미지 기반 색 선택 + 강조 1색 |
| 이모지 아이콘 | 글자 라벨, 꼭 필요하면 선 아이콘(SVG) |
| 모든 카드에 그림자 | 1px 테두리나 바탕색 차이 |
| 유리(blur) 효과 남발 | 불투명한 면 |
| 가운데 정렬 일색 | 글은 왼쪽, 숫자는 오른쪽 정렬 |
| 'Welcome back!' 같은 빈말 | 기준일 · 데이터 범위처럼 쓸모 있는 한 줄 |
| 무지개색 차트 | 회색 + 뜻이 있는 1–2색(등급 색) |
| 지나치게 둥근 모서리 | 4–8px |
| 의미 없는 장식 그림 | 빈칸(여백) |
| 영어 더미 글 | 우리말 진짜 문장 |

## 5. 대비 표

- 계산 코드: `scripts/d3_contrast.py` (WCAG 2.x 상대 휘도 공식, 실행 `uv run python scripts/d3_contrast.py`)
- 대비 = (밝은 쪽 휘도 + 0.05) / (어두운 쪽 휘도 + 0.05), 기준 4.5 : 1 이상
- 첫 후보 색에서 10쌍 모두 기준을 넘어 고친 색은 없다.

| 글자 | 바탕 | 쓰는 곳 | 대비 | 4.5 이상 |
|---|---|---|---:|---|
| `color-text` #1C1B19 | `color-bg` #F7F6F3 | 본문 · 제목 (페이지 바탕) | 15.92 : 1 | 예 |
| `color-text` #1C1B19 | `color-surface` #FFFFFF | 본문 · KPI 숫자 · 표 (카드 면) | 17.21 : 1 | 예 |
| `color-text-muted` #5E5B55 | `color-bg` #F7F6F3 | 보조 글자 · 기준일 · 바닥글 (페이지 바탕) | 6.26 : 1 | 예 |
| `color-text-muted` #5E5B55 | `color-surface` #FFFFFF | 보조 글자 · 표 머리 · 캡션 (카드 면) | 6.77 : 1 | 예 |
| `color-accent` #1F4E79 | `color-bg` #F7F6F3 | 강조 글자 (페이지 바탕) | 8.02 : 1 | 예 |
| `color-accent` #1F4E79 | `color-surface` #FFFFFF | 강조 글자 · 슬라이더 값 (카드 면) | 8.66 : 1 | 예 |
